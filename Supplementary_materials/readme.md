# Description of supplementary tables (Supplementary_tables.xlsx)

- `S1.1` AMY1 CN estimates for the complete ddPCR dataset (n=459, N=35)			
- `S1.2` AMY1 CN estimates for the read-depth (obtained from Bolognini et al., 2024) (n=1307, N=135)
